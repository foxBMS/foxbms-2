## 1. 概述

### 1.1 目的
`soc_lookup-table_cfg.h` 是一个配置头文件，为foxBMS电池管理系统中的电池剩余电量(SOC)计算模块提供配置参数和接口定义。该模块主要负责管理基于查找表的SOC估计算法所需的配置参数和宏定义。

### 1.2 应用范围
- 电池管理系统(BMS)中的状态估计算法
- 电池容量计算
- SOC百分比限制检查
- NVM(非易失性存储)值更新

### 1.3 相关模块
- 电池单元配置模块 (`battery_cell_cfg.h`)
- 电池系统配置模块 (`battery_system_cfg.h`)
- 数据库模块 (`database.h`)

## 2. 功能需求

### 2.1 配置参数定义
头文件需要定义以下关键配置参数：

#### 2.1.1 字符串容量宏定义
| 宏定义 | 单位 | 说明 |
|--------|------|------|
| `SOC_STRING_CAPACITY_mAh` | mAh | 单个电池字符串的总容量(毫安时)，由并联电池单元数和单个电池容量决定 |
| `SOC_STRING_CAPACITY_mAs` | mAs | 字符串容量转换为毫安秒，用于库伦计数 |
| `SOC_STRING_CAPACITY_As` | As | 字符串容量转换为安秒，用于精确的能量计算 |

### 2.2 容量计算逻辑
- **计算公式**：
  - `SOC_STRING_CAPACITY_mAh = BS_NR_OF_PARALLEL_CELLS_PER_CELL_BLOCK × BC_CAPACITY_mAh`
  - `SOC_STRING_CAPACITY_mAs = SOC_STRING_CAPACITY_mAh × 3600`
  - `SOC_STRING_CAPACITY_As = SOC_STRING_CAPACITY_mAs ÷ 1000`

- **转换关系**：
  - 1 Ah = 3600 As (1小时 = 3600秒)
  - 1 mAh = 3.6 mAs
  - 精度：使用浮点数(`float_t`)存储容量参数

### 2.3 依赖关系
该模块依赖以下外部配置：
- `BS_NR_OF_PARALLEL_CELLS_PER_CELL_BLOCK`：单个电池块内并联电池单元的数量
- `BC_CAPACITY_mAh`：单个电池单元的容量（毫安时）

## 3. 接口需求

### 3.1 导出函数声明
头文件应预留导出函数声明的位置，用于SOC计算的核心功能实现。

### 3.2 单元测试接口(仅在UNITY_UNIT_TEST模式下)

当编译单元测试时，头文件需要提供以下测试接口函数：

| 函数名 | 功能描述 | 返回值 |
|--------|---------|--------|
| `TEST_SE_GetSocStateInitialized()` | 获取SOC状态估计器的初始化状态 | bool - 初始化状态标志 |
| `TEST_SOC_CheckDatabaseSocPercentageLimits(DATA_BLOCK_SOC_s *TableSoc, uint8_t stringNumber)` | 检查SOC百分比是否在允许的数据库限制范围内 | void |
| `TEST_SOC_UpdateNvmValues(DATA_BLOCK_SOC_s *TableSoc, uint8_t stringNumber)` | 更新非易失性存储器中的SOC值 | void |

### 3.3 数据结构
- `DATA_BLOCK_SOC_s`：SOC数据块结构体，用于存储SOC相关的计算结果和状态

## 4. 非功能需求

### 4.1 代码质量
- **编码标准**：符合foxBMS项目编码规范
- **注释规范**：采用Doxygen文档格式
- **头文件保护**：使用`FOXBMS__SOC_LOOKUP_TABLE_CFG_H_`宏防止重复包含
- **文件编码**：UTF-8

### 4.2 性能要求
- 宏定义应采用编译期计算，无运行时开销
- 浮点数计算应使用标准C库的数学函数
- 容量参数应以常数形式定义，便于编译器优化

### 4.3 可靠性要求
- 所有容量相关的计算应使用浮点数(`float_t`)保证精度
- 单位转换因子应准确(例如3600用于小时到秒的转换)
- 多字符串(多电池包)场景下应正确处理单位转换

### 4.4 可维护性要求
- 宏定义应提供清晰的注释说明其用途和单位
- 所有常数应集中定义在该头文件中
- 应避免硬编码数值，使用宏定义替代

## 6. 配置参数说明

### 6.1 字符串容量(SOC_STRING_CAPACITY_mAh)
- **定义**：一个电池字符串中所有并联电池单元的总容量
- **计算方式**：`并联电池数量 × 单个电池容量`
- **数据类型**：`float_t`
- **用途**：作为Coulomb计数法(库伦计数)中的参考容量
- **示例**：若系统配置为10个并联单元，每个单元容量为3000mAh，则总容量为30000mAh

### 6.2 毫安秒容量(SOC_STRING_CAPACITY_mAs)
- **定义**：字符串容量以毫安秒为单位表示
- **转换关系**：`容量(mAs) = 容量(mAh) × 3600`
- **用途**：在库伦计数算法中用于直接累加电流值

### 6.3 安秒容量(SOC_STRING_CAPACITY_As)
- **定义**：字符串容量以安秒为单位表示
- **转换关系**：`容量(As) = 容量(mAs) ÷ 1000`
- **用途**：与库伦计数器累计值进行对比，用于百分比SOC的计算
