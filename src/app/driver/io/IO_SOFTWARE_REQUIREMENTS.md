# IO — 通用输入输出驱动软件需求规格说明

## 1. 引言

### 1.1 目的
本文档定义 foxBMS 2 中 IO（Input/Output）驱动模块的软件需求。IO 模块提供对 MCU 通用 I/O 引脚的低级操作，包括引脚方向设置、输出置位/复位和输入状态读取。

### 1.2 范围
- **涵盖**：引脚方向控制、引脚输出控制、引脚输入读取
- **不涵盖**：外设 GPIO 寄存器（由各外设驱动自行管理）

### 1.3 定义与缩略语
| 术语 | 说明 |
|------|------|
| GIO | General Input/Output，通用输入输出 |
| TMS570LC43 | TI Hercules 安全 MCU 型号 |

### 1.4 参考文献
- TMS570LC43 技术参考手册

## 2. 总体描述

IO 模块是 foxBMS 最底层的引脚操作驱动，提供对内存映射 I/O 寄存器的位操作。位于 DRIVERS 层。

## 3. 功能需求

#### REQ-001 — 引脚方向设置（输出）
**优先级**：高 | **函数**：`IO_SetPinDirectionToOutput()`

模块应通过写入引脚方向寄存器将指定引脚设置为输出模式。

#### REQ-002 — 引脚方向设置（输入）
**优先级**：高 | **函数**：`IO_SetPinDirectionToInput()`

模块应通过写入引脚方向寄存器将指定引脚设置为输入模式。

#### REQ-003 — 引脚置位
**优先级**：高 | **函数**：`IO_PinSet()`

模块应通过写入引脚输出寄存器将指定引脚拉高。

#### REQ-004 — 引脚复位
**优先级**：高 | **函数**：`IO_PinReset()`

模块应通过写入引脚输出寄存器将指定引脚拉低。

#### REQ-005 — 引脚状态获取
**优先级**：高 | **函数**：`IO_PinGet()`

模块应读取引脚输入寄存器的指定位，返回 `STD_PIN_STATE_e`（高/低）状态。

## 4. 非功能需求

- **REQ-006**：所有函数直接操作 volatile 寄存器指针，确保编译器不优化
- **REQ-007**：函数为简单寄存器写入操作，时间复杂度 O(1)

## 5. 接口需求

### 5.1 公共 API
| 函数 | 说明 |
|------|------|
| `IO_SetPinDirectionToOutput(reg, pin)` | 设置引脚为输出 |
| `IO_SetPinDirectionToInput(reg, pin)` | 设置引脚为输入 |
| `IO_PinSet(reg, pin)` | 引脚置高 |
| `IO_PinReset(reg, pin)` | 引脚置低 |
| `IO_PinGet(reg, pin)` | 获取引脚状态 |

### 5.2 依赖项
`fstd_types.h`
